# 도시·지역개발 연구실 홈페이지

국립목포대학교 도시계획및지역개발학전공 도시·지역개발 연구실(지도교수 홍석호) 홈페이지입니다.

- 홈페이지: https://mnu-urdlab.github.io/mnu-urdlab/
- 관리 화면: https://app.pagescms.org

## 내용 수정은 관리 화면에서

공지사항, 연구실 행사 사진, 자료실, 논문, 연구실적, 구성원, 교수 약력, 언론보도는 모두 **관리 화면(Pages CMS)** 에서 입력 칸을 채워 수정합니다. 코드를 고칠 필요가 없습니다.

1. https://app.pagescms.org 접속
2. 로그인
   - GitHub 계정이 있는 사람: **Sign in with GitHub**
   - GitHub 계정이 없는 사람(교수님 등): 관리자에게 초대받은 이메일로 로그인 (메일로 로그인 링크가 옵니다)
3. `mnu-urdlab` 저장소 선택
4. 왼쪽 메뉴에서 수정할 항목 선택 → 내용 입력 → **Save**
5. 1~2분 뒤 홈페이지에 반영 (안 보이면 Ctrl+F5)

### 자주 하는 작업
- **공지 올리기**: 게시판 → 공지사항 → 맨 아래 **Add an entry** → 분류·작성일·제목·본문 입력 → Save
- **답사 사진 올리기**: 게시판 → 연구실 행사 → Add an entry → 날짜·행사명 입력 → 사진 칸에서 업로드(여러 장 가능, 첫 장이 대표사진) → Save
- **논문 추가**: 연구 → 논문·저서 → Add an entry → 연도·제목·저자·학술지 → Save
- **구성원 추가/졸업 처리**: 구성원 → 구성원 → 구분을 '졸업생'으로 바꾸면 졸업생 목록으로 이동

목록 순서는 신경 쓰지 않아도 됩니다. 홈페이지에서 날짜·연도 순으로 자동 정렬됩니다.
영어 칸(영어, 선택)은 비워두면 영어 화면에서도 한국어로 보입니다.

## 권한 관리 (관리자용)
- **GitHub 계정이 없는 분 초대**: 관리 화면 → 저장소 설정의 **Collaborators** 에서 이메일로 초대
- **GitHub 계정이 있는 분 초대**: GitHub 저장소 → Settings → Collaborators → Add people
- `mnu-urdlab` GitHub 계정이 최상위 관리자 계정입니다. 비밀번호는 교수님이 관리하세요.

## 파일 구성
| 경로 | 내용 |
| --- | --- |
| `index.html`, `app.js` | 홈페이지 디자인·기능 (평소에는 건드리지 않음) |
| `data/*.json` | 홈페이지 내용 (관리 화면이 자동으로 수정) |
| `images/` | 사진 |
| `files/` | 첨부파일 |
| `.pages.yml` | 관리 화면 설정 |

## 주의
- 이 저장소와 홈페이지는 **공개**입니다. 개인 휴대폰 번호, 내부 보고서, 예산 자료 등은 올리지 마세요.
- 잘못 저장했으면 GitHub 저장소의 해당 파일 → **History** 에서 이전 버전으로 되돌릴 수 있습니다.
